Save safely

Default: 3. Applying removes excess editor backups for the open file now; other files use the limit when opened or saved. 0 removes all eligible backups and disables recovery copies. Downloaded copies are separate and are never pruned.

Manual Save asks before replacing the native-opened file. Autosave on change is explicit consent to save committed valid changes without another prompt. Export a separate copy instead if you prefer.

Only verified values on existing objects can change. Object references and unknown data stay untouched.

Bulk targets

Apply targets before using Maximize all or Repair & Top Off. Changing these settings does not edit a save.
